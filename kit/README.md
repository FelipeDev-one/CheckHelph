# CheckHelph · paquete MVP

Este paquete contiene la identidad visual, las láminas del MVP y un prototipo navegable de demostración.

## Prototipo

Abre `prototipo/index.html` en un navegador. Puedes navegar entre Inicio, Tareas, Bloqueos y Traspasos; marcar tareas, registrar bloqueos y guardar entregas de turno. La demostración guarda sus datos en el almacenamiento local del navegador. Usa **Reiniciar demo** para volver a los datos iniciales.

Los datos son ficticios. El prototipo no tiene backend, autenticación ni controles de seguridad productivos.

## Logos

En `brand/` están el logo principal, secundario, submarca **CheckHelph Equipo** y favicon en SVG y PNG. Los SVG son la versión vectorial recomendada para web y para importar como vectores en Figma.

Paleta: petróleo `#16333B`, teal `#0F6B63`, menta `#DDF1EA`, marfil `#F5F3ED`, ámbar `#E2A43A` y grafito `#263A40`.

## Figma

Las pantallas del prototipo están conectadas en la versión web. Para editar el proyecto y compartirlo como archivo/prototipo de Figma, se debe conectar Figma a esta conversación. Los SVG de marca ya son importables en Figma.
